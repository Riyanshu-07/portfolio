---

## ⚡ Key Systems & Features

- **AETHER — AI Digital Twin**: Server-side conversational intelligence powered by Gemini 3.8 Flash with context grounding, system prompts, and heuristic neural fallback resilience.
- **Simulated Ray-Traced 3D Canvas**: Dual-hemisphere neural network visualizer with dynamic key, fill, and rim lights that adapt to cursor momentum and theme transitions.
- **Theme Switcher**: 5 distinct operational modes (`Cyberpunk OS`, `Amber Luxury`, `Matrix Quantum`, `Nebula Synth`, and `Titanium Tech`).
- **Interactive ML Sandboxes**:
  - *AdaIN Neural Style Transfer*: Real-time content and style feature alignment with dynamic intensity weighting and VGG-19 activation graphs.
  - *SmartFocus SHAP Explainability*: Feature contribution breakdown (Blink Rate, PERCLOS, Head Pose) with real-time prediction confidence.
- **Quantum Particle Physics Playground**: Canvas physics simulation with adjustable gravity, collision elasticity, vortex singularities, spatial audio, and haptic feedback.
- **Cryptographic Anti-Cheat System**: Client-side frame-delta anomaly detection paired with server-side HMAC-SHA256 signature verification for score submissions.
- **Live System Telemetry**: Real-time FPS, frame latency, memory allocation tracking, and cloud state export/import.
- **Quick Command Palette (`⌘K`) & Interactive Terminal**: Full CLI mode supporting bash-like navigation (`theme`, `status`, `eval`, `export`).

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/Riyanshu-07/riyanshu-os.git
cd riyanshu-os
npm install
```

### 2. Configure Environment Variables
Create a `.env` file based on `.env.example`:
```bash
cp .env.example .env
```
Add your Gemini API key (optional for local neural fallback, required for live model queries):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Run Development Server
```bash
npm run dev
```
The application will launch at `http://localhost:3000`.

### 4. Production Build
```bash
npm run build
npm start
```
