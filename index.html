Adaptive Instance Normalization (AdaIN) Forward Flow

Rather than iterating through hundreds of gradient optimization passes on raw pixel tensors, AdaIN transforms channel statistics directly in feature space:

AdaIN(x, y) = σ(y) · [ (x - μ(x)) / σ(x) ] + μ(y)
Where: x ∈ ℝ^(C×H×W) is the content activation, y ∈ ℝ^(C×H×W) is the style activation. Channel-wise moments μ, σ are computed independently across spatial dims (H, W).
INTERACTIVE ALPHA (α) STYLE STRENGTH: 0.75
CONTENT LOSS L_c: 0.142 (low preservation drift)
STYLE LOSS L_s: 0.829 (high texture transfer)

RealityDiff Spatial-Temporal Confirmation Gate

Raw detections fluctuate wildly between consecutive frames. RealityDiff passes candidate bounding boxes through a dual-threshold Kalman-filtered tracking bank:

Spatial Overlap IoU(B_t, B_(t-k)) > τ_spatial ∧ Frame Persistence Δt > 1.5s
If an object disappears or appears, it must survive the temporal buffer before triggering an alert, suppressing pedestrians or cars crossing the scene.
// TRACKING STACK
Detector: YOLO26 Tiny/Nano
Under 12ms inference per frame on CUDA
Tracker: BoT-SORT
Camera Motion Compensation (CMC) + ReID embeddings
Storage: Supabase PostgreSQL
Real-time state logs & snapshot storage

SnapClass Dual Biometric Identity Verification

Prevents photo/video replay spoofing by requiring concurrent facial Euclidean alignment with voice harmonic d-vector distance matching:

Decision = [ ‖v_face - v_enrolled‖₂ < 0.60 ] ∧ [ cos(θ_voice) > 0.78 ]
A photo held up to the camera fails the acoustic voice embedding match; a recorded voice fails the 68-point dynamic facial landmark motion check.
// ACCURACY & HARDENING

Dlib affine-aligned ResNet-34 backbone
Voice Model: Resemblyzer d-vector
